Popup interativo

Este é um exemplo simples de um popup modal criado com HTML, CSS e JavaScript. Clique no botão abaixo para abrir o popup.

Título do popup

Você pode colocar qualquer conteúdo aqui dentro, como textos, formulários ou imagens. Este popup inclui um fundo semitransparente e fecha ao clicar fora do conteúdo ou no botão de fechar.
