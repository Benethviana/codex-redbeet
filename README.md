# Exemplo de Popup Modal

Este projeto simples mostra como criar um popup (modal) acessível usando HTML, CSS e JavaScript.

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno. Clique no botão "Abrir popup" para visualizar o componente em ação.

## Funcionalidades

- Animação suave de entrada e saída
- Fundo semitransparente com efeito _blur_
- Fechamento pelo botão, pelo botão cancelar, clique fora do conteúdo ou tecla `Esc`
- Ajustes responsivos para telas menores
- Suporte a preferências de tema claro/escuro do sistema
